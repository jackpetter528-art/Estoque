# 📦 Sistema de Controle de Estoque

Projeto desenvolvido em **Python** com o objetivo de simular o gerenciamento de estoque de uma loja, permitindo cadastrar produtos, controlar quantidades e acompanhar informações sobre os produtos disponíveis.

O sistema funciona diretamente pelo terminal, utilizando menus interativos para que o usuário consiga realizar as operações.

## 🚀 Funcionalidades

- Cadastro de produtos.
- Listagem dos produtos cadastrados.
- Registro de compras e atualização da quantidade em estoque.
- Reposição de produtos.
- Relatório com informações gerais do estoque.
- Validação de dados inseridos pelo usuário.
- Tratamento de erros durante a execução.

## 🛠️ Tecnologias utilizadas

- **Python:** linguagem utilizada no desenvolvimento.
- **JSON:** recurso utilizado para trabalhar com dados.
- **Try/Except:** tratamento de possíveis erros.
- **Estruturas de dados:** listas e dicionários para organizar as informações dos produtos.
- **Funções:** organização e reutilização do código.

## ▶️ Como executar o projeto

1. Tenha o Python instalado no computador.
2. Baixe ou copie este repositório.
3. Abra a pasta do projeto no VS Code ou terminal.
4. Execute o comando:

```
python main.py
```
